The final handoff intentionally does not redistribute the fixed GitHub source,
the full published CSV, or the 98.6 MB Zenodo archive. It records exact hashes,
locators, reconstruction receipts, and derived outputs. The Zenodo API reports
CC BY 4.0 for the deposited record; the earlier fixed-commit GitHub rights audit
did not identify a repository licence. Omitting third-party full bytes keeps this
review handoff compact and avoids silently treating a public repository as a
redistribution licence.
